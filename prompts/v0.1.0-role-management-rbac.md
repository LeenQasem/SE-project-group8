## Key Instructions Sent to Agent

- Implement `rbac.py` with `has_role` to check an authenticated user's assigned role, `require_role` as a reusable authorization guard for a specified role, and `require_admin` as the administrator-only guard. Support all three project roles and reject absent/unauthenticated users rather than granting access.
- Implement `bootstrap_admin.py` to create the initial `ADMINISTRATOR` only through a guarded bootstrap path. Hash its password with the project's salted password-hashing mechanism; never store a plain-text password. Preserve the existing seed data and do not edit `src/database/seed.sql`.
- In `user_management_service.py`, require administrator authorization before `assign_role` changes a user's role and before `view_users` returns user listings. Reject unauthenticated and non-administrator callers; allow valid administrator role assignments.
- Add unit tests in `test_rbac.py` and `test_user_management_service.py` covering role checks and these authorization outcomes, including valid administrator assignments.
- Follow the existing backend conventions and limit changes to the listed implementation and test modules.
